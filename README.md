# Source Jar

**Source Jar** is a website for finding open source software. It collects well-known open source tools in one place and shows each one with a short description, its license and a link to the project.

The site works like making a sandwich. You pick a jar of spread, drag a butter knife across a slice of bread, and the tools appear in the spread as you go. Each tool you uncover gets a card below the bread so you can read about it and visit the project.

## What's on the site

- **60 open source tools** in five categories, one per jar.
- **A card for every tool** with what it does, its license and a link to its website or repository.
- **Spread Facts**, a panel styled like a food nutrition label that counts the tools you've found and breaks them down by license (MIT, Apache, GPL, BSD, MPL and others).
- **Spread the whole slice** reveals every tool in the current jar at once. **Fresh slice** starts over.
- Works on desktop and phones, in light and dark mode.

## Run it locally

The site is a single `index.html` file with no build step and no dependencies to install. Open it in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Put it online

Turn on GitHub Pages for this repo: **Settings → Pages → Deploy from a branch → `main` / root**. The site will be published at https://emperorkaido99.github.io/Source-Jar/.

## Add a tool

All tools live in the `JARS` array near the top of the `<script>` in `index.html`. Add an entry to the jar it belongs in:

```js
{ n: "Name", lic: "SPDX license", d: "One-line description.", url: "https://project.site" }
```

Add `s: "Short name"` if the full name is too long to fit on the bread. Each jar lays its tools out in rows of three, so adding tools in multiples of three keeps the slice tidy.
